# 文字总表格式

开写 `film.js` 之前交付。用户确认后，表里的字才允许上屏。

## 模板

```markdown
# 《片名》文字总表

论点：…
贯穿词：…

## 字幕 sub

| 起-止(s) | 中文（{金} {!红}） | 英文(C) | 站 |
|---|---|---|---|
| 1.2–7.6 | 一个连止痛药都吃不起的乡村教师—— | … | 钩子 |

## 画面字

| 起-止(s) | 层 | 位置 | 中文 | 英文? | 作用 | 与字幕 |
|---|---|---|---|---|---|---|
| 0–4 | hook | 中央大字 | 止痛药都吃不起 | — | 命名冲击 | 互补（短冲击；完整句在 sub） |
| 8–32 | label | 左上 | 左 · 银河 | — | 定位 | 互补 |
| 8–32 | label | 右上 | 右 · 古井村 | — | 定位 | 互补 |
| 8–32 | label | 舰队旁 | 人造太阳 | — | 命名 | 互补；勿写整句解说 |
| 32–40 | label | 右栏数字 | 1–10 bit/s | — | 报数 | 互补 |
| — | mark | 左上 | 00 问 / HOOK | — | 定位 | — |
```

`与字幕` 只许三个值：`互补` | `可删` | `禁止复述`。

## 层取值

`sub` · `title` · `mark` · `hook` · `label` · `card` · `ui` · `hud`

## 自查

- [ ] 每一条将上屏的字都在表里（含卡片内行、黑板上的公式、UI 状态）
- [ ] 无「禁止复述」却仍计划写近义整句
- [ ] 同一秒最多一层在「讲故事」；其他层只报数/命名/定位
- [ ] C：英文不与中文同义双行（字幕 en 行除外）
- [ ] 表已给用户看过并确认

## 落代码

```js
// 字幕
const SUBS = [ { a, b, zh, en } ];

// 章节
const MARKS = [ { t, no, zh, en } ];

// 其余：按镜常量化，勿在绘制里现编
const COPY = {
  hookShock: ['止痛药都吃不起', '凭什么拦住十万艘舰'],
  split: { left: '左 · 银河', right: '右 · 古井村' },
};
```

改文案时先改总表，再改常量，再渲静帧核对。
