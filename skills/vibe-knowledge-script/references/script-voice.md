# 字幕文体（读的，不是念的）

完整句式与骨架示例见 film skill：`../vibe-knowledge-film/references/script.md`。这里只留写总表时要用的硬数字。

## 量

| | 每分钟句数 | 每句字数（均/最长） | 停留 |
|---|---|---|---|
| B 寓言 | ~15 | 13 / 18 | ~3.5s |
| C 夜曲 | 8–10 | 15–21 / 28（中文） | 5–6s |

- 一行放不下就拆成两句、两个动作。
- 全片 26–42% 时间无字幕（片名、转场、纯画面演）。
- 画面字不占「句数配额」，但占注意力：同屏画面字越多，字幕越要短。

## 骨架

钩子（6–24s）→ 片名 → 主体 4–12 站 → 转向「你」→ 回扣钩子 → 片尾文献。

## 句式优先

两半句翻转 · 破折号后给答案 · 问句 · 一句话写一个人 · 「不是…是…」极少 · 对「你」说 · 数字具体 · 末句回声片名。

禁止：寒暄预告、总结腔、形容词堆、众所周知。

## 和画面字的边界

- 叙事、转折、问句 → `sub`
- 名字、数字、左右、状态灯 → `label` / `ui` / `hud`
- 一击钩住 → `hook`（短），完整问题仍进 `sub`
