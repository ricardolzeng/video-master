# 全片文字层（脚本）

无旁白片子里，观众读的不只是底下一行字幕。屏上凡是能读出来的字，都属于本 skill。

和 `vibe-knowledge-film` 的分工：
- **本 skill**：字写什么、何时出现、和字幕什么关系、怎么验收。
- **film skill**：形象、分镜、画法、渲染、声音。

句长、骨架、句式细节见 [references/script-voice.md](references/script-voice.md)（从 film skill 的 `script.md` 抽出）。总表格式见 [references/copy-sheet.md](references/copy-sheet.md)。

## 六层字

| 层 | 代码入口 | 干什么 | 默认上限 |
|---|---|---|---|
| `sub` | `SUBS` + `K.subs` | 叙事句，观众跟着读完片子 | C 中文 ≤28 字；B ≤18 |
| `title` | `titleNight` / `titleGilt` | 片名 / 副题 / 外文行 | 片名 2–5 字 |
| `mark` | `MARKS` + `chapterMark` | 现在第几章 | 中文 1 字 + 英文词 |
| `hook` | 开场 / 命名 `fr.text` | 一眼钩住或给概念起名 | ≤10 字 |
| `label` | 贴主体的小字 | 报数、命名零件、定位左右 | ≤8 字 |
| `card` / `ui` / `hud` | 卡片标题、面板、年份出处 | 装置内可读信息 | 标题 ≤6 字；勿整句复述字幕 |

**硬规则：同一秒内，`sub` 与其他层禁止同义叠读。**  
字幕说完整句；画面字只做命名 / 报数 / 定位 / 出处。字幕已说清的话，删掉画面上那句说明。

## 流程

### 1. 立论点 + 贯穿词

写下：一句话论点；全片只用的那一个意象词（假蛋 / 惊奇 / 粉笔…）。后面每层字都尽量能挂上这个词。

### 2. 先写字幕稿

按 `script-voice.md`：量、骨架、句式。一行一句，带大致起止秒。  
过关：只读字幕是一篇通顺短文；每句里有屏上能演的名词或动词。

### 3. 写文字总表（开 `film.js` 之前）

把字幕扩成总表，**补上每一镜会出现的画面字**。格式见 `copy-sheet.md`。  
交给用户确认。没确认不写 `fr.text`。

过关：
- 每一行有层、时刻、原文、作用、与字幕关系；
- 标成 `禁止复述` 的，画面上不许再写近义整句；
- 钩子大字与首句字幕不同词，或明确 `hook` 先出、`sub` 后出且职责不同。

### 4. 落进代码

- 字幕 → 只进 `SUBS`。
- 章节 → 只进 `MARKS`。
- 其余 → 可先收成 `ON_SCREEN` / 各镜常量表，再 `fr.text`；禁止在绘制函数里随手新造用户没签过的句子。
- 染色：`{词}` 金、`{!词}` 红；一句字幕最多染一处。

### 5. 验收

1. 静帧：`--stills` / `--sheet`，**读屏上所有字**，对照总表；多字删、少字补、错字改。
2. 只读字幕一遍；再遮字幕只读画面字——两层合起来才等于故事，单独一层不应像另一层的复读机。
3. `read_subs.py` 核对底部字幕（不管画面字）。
4. 可选：从 `film.js` 抽出字符串字面量，与总表做差集（多写的 / 漏写的）。

## 反面（来自乡村教师加厚版一类片子）

- 字幕已经在讲「左边舰队 / 右边窑洞」，屏上再写一整句说明 → 删画面句，只留「左」「右」或物件名。
- 审判面板堆英文整句（`SINGULARITY ARMED`）又与中文字幕平行叙事 → 英文缩到气质标签，叙事回字幕。
- 卡片标题 + 卡片内两行 + 底部字幕三线同时讲同一件事 → 卡片只留标题，细节进字幕或进画面动作。
- 钩子大字与字幕同一句换词复读 → 大字用短冲击短语，完整疑问留给字幕。

## 返工话术（对用户或对模型）

| 毛病 | 怎么说 |
|---|---|
| 画面字和字幕说同一句 | 删屏上这句。字幕负责叙事，屏上只留 [名称/数字]。 |
| 标注太长 | 砍到 8 字内；多出口的进字幕。 |
| 中英双句同一意思 | 只留中文；英文留给章节标或符号。 |
| 不知道屏上该有什么字 | 先补文字总表，再改 `film.js`。 |
| 只改了字幕画面还是旧词 | 全局搜旧字符串；总表和代码一起改。 |

## 不做

- 不改 `vk.js` / 渲染管线。
- 不把口播稿当字幕。
- 不用后期烧录替代 `K.subs`。
- 不在本 skill 里找形象或写道具几何（回 film skill）。
